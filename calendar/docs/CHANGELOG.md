# Changelog

- 1: The calendar: CalDAV on the box (Radicale, one `.ics` per event in `input/calendar/`), an app for every device with month, week, day and list views, repeating events with "this and following", several reminders per event, places with map links, colored calendars, import and export, offline changes with conflict rules, copies kept when the box loses events, phones' own calendar apps connected for reliable reminders.
